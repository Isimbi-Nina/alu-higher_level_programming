integer_validator()
--------------------

Valid positive integers do not raise anything::

    >>> bg.integer_validator("my_int", 12)
    >>> bg.integer_validator("width", 89)

A string value raises a TypeError::

    >>> bg.integer_validator("name", "John")
    Traceback (most recent call last):
    TypeError: name must be an integer

A float value raises a TypeError::

    >>> bg.integer_validator("distance", 3.14)
    Traceback (most recent call last):
    TypeError: distance must be an integer

A boolean value raises a TypeError, since bool is not treated as int::

    >>> bg.integer_validator("flag", True)
    Traceback (most recent call last):
    TypeError: flag must be an integer

Zero raises a ValueError::

    >>> bg.integer_validator("age", 0)
    Traceback (most recent call last):
    ValueError: age must be greater than 0

A negative integer raises a ValueError::

    >>> bg.integer_validator("distance", -4)
    Traceback (most recent call last):
    ValueError: distance must be greater than 0

None raises a TypeError::

    >>> bg.integer_validator("value", None)
    Traceback (most recent call last):
    TypeError: value must be an integer
