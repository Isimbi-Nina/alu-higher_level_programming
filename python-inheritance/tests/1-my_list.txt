The ``1-my_list`` module
=========================

Using MyList
------------

Import the class::

    >>> MyList = __import__('1-my_list').MyList

Create a list, append integers, and print it sorted::

    >>> my_list = MyList()
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]
    >>> print(my_list)
    [1, 4, 2, 3, 5]

Test with an empty list::

    >>> empty = MyList()
    >>> empty.print_sorted()
    []

Test with negative numbers::

    >>> neg = MyList()
    >>> neg.append(-1)
    >>> neg.append(-5)
    >>> neg.append(0)
    >>> neg.print_sorted()
    [-5, -1, 0]

Test that MyList is indeed a list::

    >>> isinstance(my_list, list)
    True
