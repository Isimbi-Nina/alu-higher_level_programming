# python-more_data_structures

This project is a collection of Python exercises covering sets, dictionaries,
lambdas, and the `map`, `filter`, and `reduce` functions.

## Learning Objectives

At the end of this project, you should be able to explain:

- Why Python programming is awesome
- What sets are and how to use them
- The most common methods of a set
- When to use sets versus lists
- How to iterate over a set
- What dictionaries are and how to use them
- When to use dictionaries versus lists or sets
- What a key in a dictionary is
- How to iterate over a dictionary
- What a lambda function is
- What the `map`, `reduce`, and `filter` functions are

## Requirements

- Allowed editors: `vi`, `vim`, `emacs`
- All files are interpreted on Ubuntu 20.04 LTS using `python3` (version 3.8.5)
- All files end with a new line
- The first line of every file is exactly `#!/usr/bin/python3`
- Code follows `pycodestyle` (version 2.7.*)
- All files are executable
- No modules are imported unless explicitly permitted

## Tasks

| # | File | Description |
|---|------|-------------|
| 0 | `0-square_matrix_simple.py` | Square every value of a matrix |
| 1 | `1-search_replace.py` | Replace all occurrences of an element in a new list |
| 2 | `2-uniq_add.py` | Add all unique integers in a list |
| 3 | `3-common_elements.py` | Return common elements of two sets |
| 4 | `4-only_diff_elements.py` | Return elements present in only one of two sets |
| 5 | `5-number_keys.py` | Return the number of keys in a dictionary |
| 6 | `6-print_sorted_dictionary.py` | Print a dictionary ordered by key |
| 7 | `7-update_dictionary.py` | Add or replace a key/value pair in a dictionary |
| 8 | `8-simple_delete.py` | Delete a key from a dictionary |
| 9 | `9-multiply_by_2.py` | Return a new dictionary with all values doubled |
| 10 | `10-best_score.py` | Return the key with the highest value |
| 11 | `11-multiply_list_map.py` | Multiply list values by a number, using `map` |
| 12 | `12-roman_to_int.py` | Convert a Roman numeral to an integer |

## Usage

Each task has a corresponding `N-main.py` file demonstrating usage, e.g.:

```
./0-main.py
```
